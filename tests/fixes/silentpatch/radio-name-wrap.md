# Radio station name wrap

Group `radio-name-wrap` (call_redirect at 0x4e9f7a).

**Port.** The centre size is set to the screen width after the name's drop colour, as SilentPatch.

**Reproduction.** Not scripted yet. The M9 route lists whether the name is drawn.

**Result.** Lifted and converted.
